# User guide

## Now Playing

Paste a media URL and use Play URL, Previous, Pause/Resume, Next, and seek buttons (±10s / ±30s). Video opens in the mpv window.

## Search

Enter a YouTube query. Select a result, then **Play Now** or **Add to Queue**.

## Queue

Shows the current mpv playlist. Play selected/all, remove items, or clear with confirmation.

## Open

Enter a URL, browse local media, or open an M3U channel list. When a playlist loads, the right panel shows Channel / Group browsing. Selecting a channel fills the entry; it does **not** auto-play.

## History

Recently opened media. Replay, queue, copy URL, delete, or refresh.
